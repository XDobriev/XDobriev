Я не «прохожу курсы» — я **довожу продукты до пользователей**. Мой главный проект — это работающий SaaS с реальной оплатой, авторизацией через несколько провайдеров, админ-панелью и CI/CD на боевой VPS. > Редактор для писателей: рукопись, картотека персонажей, карта мира и хронология в одном тихом редакторе.

- 🗺️ Карта мира на SVG (zoom/pan, штампы рельефа), хронология и персонажи с drag & drop (**@dnd-kit**)
- 🔐 Авторизация email + **Telegram OAuth + VK ID**, **RLS-политики** (каждый видит только свои данные)
- 💳 Оплата через **Робокассу** (СБП + карты), рекуррентные списания, возвраты, тарифы Free / Pro / Lifetime
- 📊 **Админ-панель**: DAU/WAU/MAU, retention, revenue-метрики, feature flags, audit log
- 📤 Экспорт в **DOCX / FB2 / EPUB / PDF / HTML / Markdown**, мобильный адаптив, offline-баннер
- 🚀 **Деплой на Timeweb VPS** (Ubuntu, Nginx, Let's Encrypt) через **GitHub Actions**, Sentry для ошибок

`React 18` · `TypeScript (strict)` · `Vite` · `Framer Motion` · `TipTap` · `Supabase` · `GitHub Actions` · `Sentry`
